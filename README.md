# 💼 Profit Prediction using Linear Regression

This project uses **Linear Regression** to predict a company’s **profit** based on multiple input features like R&D Spend, Administration, and Marketing Spend.  
The dataset was taken from [Kaggle - Profit Prediction Dataset](https://www.kaggle.com/datasets/studymart/profit-prediction-using-linear-regression).

---

## 📊 Project Overview
This is a simple yet effective **Machine Learning Regression Project** implemented in Python using Google Colab.

### 🚀 Key Steps:
- Data Cleaning and Preprocessing  
- Exploratory Data Analysis (EDA) using Seaborn & Matplotlib  
- Model Training with Linear Regression  
- Performance Evaluation using **R² Score**

---

## 🧠 Tools and Libraries
- Python 🐍  
- NumPy  
- Pandas  
- Matplotlib  
- Seaborn  
- Scikit-learn  

---

## 📈 Model Performance
| Metric | Score |
|:--------|:------|
| R² Score | 0.88 |

> The model shows a high correlation between predicted and actual profit values.
